# Telegram-бот для поиска на ГДЗ.ру

Бот принимает текст или фото, распознаёт текст на фотографии через Tesseract OCR и ищет страницы, размещённые на `gdz.ru`. Поиск выполняется через поисковый индекс; в ответах бот оставляет только ссылки на `gdz.ru`.

## Возможности MVP

- Текстовый запрос: `упр 13 7 класс русский язык`
- Поиск контрольных по теме/параграфу: `история 7 класс параграф 5 контрольная`
- Фото задания: OCR распознаёт текст и отправляет его в поиск
- Фильтрация результатов: только домен `gdz.ru`
- Команды `/start`, `/help`, `/search`

## 1. Создай Telegram-бота

1. Открой `@BotFather` в Telegram.
2. Выполни `/newbot` и следуй инструкциям.
3. Скопируй токен. Не публикуй его и не отправляй посторонним.

## 2. Установка на Linux-хостинге

Загрузи `main.py` и `requirements.txt` на хостинг. Нужен Python 3.10+ и возможность запускать постоянный процесс.

На Ubuntu/Debian установи OCR:

```bash
sudo apt-get update
sudo apt-get install -y tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng
```

Создай виртуальное окружение и поставь библиотеки:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Задай токен в переменной окружения:

```bash
export BOT_TOKEN="ВСТАВЬ_СЮДА_ТОКЕН_ОТ_BOTFATHER"
python main.py
```

Для работы 24/7 включи режим постоянного процесса в панели хостинга. Если панель поддерживает секретные переменные/Environment Variables, лучше задать `BOT_TOKEN` там, а не хранить в файле.

## 3. Пример использования

- `упр 13 7 класс русский язык`
- `математика 6 класс Виленкин номер 245`
- `история 7 класс параграф 5 контрольная`

Или отправь фото задания. Чем чётче фотография, тем лучше OCR.

## Ограничения

- Это стартовая версия: поиск зависит от доступности поискового индекса и сетевых ограничений хостинга.
- Бот возвращает ссылки и короткие сниппеты, а не копирует целые страницы сайта.
- По фото контрольной может найти похожие материалы, но точное совпадение не гарантируется.
- Некоторые материалы на ГДЗ.ру могут требовать входа; бот не обходит авторизацию и не получает закрытый контент.
- Если поисковый индекс блокирует хостинг или меняет HTML, потребуется обновить функцию `search_gdz`.
- Убедись, что автоматические запросы соответствуют правилам сайта и не отправляй запросы слишком часто.

## Устранение неполадок

**`Не задан BOT_TOKEN`** — добавь переменную окружения `BOT_TOKEN`.

**OCR не работает** — установи системные пакеты Tesseract, `tesseract-ocr-rus`, `tesseract-ocr-eng` и Python-пакеты из `requirements.txt`.

**Результатов нет** — уточни предмет, класс, автора, тему или номер задания; попробуй `/search история 7 класс параграф 5`.

**Бот останавливается** — проверь логи хостинга и настрой постоянный процесс/автоперезапуск.


## Bothost с распознаванием фото

В архив добавлен `Dockerfile`: он устанавливает Tesseract OCR и русский/английский языковые пакеты. На Bothost выбери запуск через Dockerfile, если такая опция доступна. Если в настройках хостинга задан `BOT_TOKEN`, он имеет приоритет над тестовым токеном, указанным в коде. Для настоящего бота рекомендуется удалить токен из `main.py` и хранить его только в переменных окружения Bothost. Не публикуй рабочий токен в GitHub.
